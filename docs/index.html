01

Local metrics show candidates, not the final answer

Local metrics identify which stations deserve attention, but they do not directly answer which capacity addition improves the whole line most. FURNACE is slow per batch and processes the most lots per run, while LITHO has the highest utilization. The decision needs a system-level what-if comparison.

局部指標能指出候選站點，但不是最後答案

局部指標可以告訴我們哪些站點值得注意，但不能直接回答「加哪一站的產能，對整條線改善最大」。 FURNACE 單批加工時間最長、每次運轉可處理最多 lots；LITHO 的稼動率最高。因此還需要用整體系統的 what-if 比較來判斷。

02

An improvement is not automatically a good investment

Finding 01 answers one question: which added tool reduces the line's average cycle time the most.

But that is not the full decision. Every +1 tool option has a cost, and a cycle-time improvement is not automatically large enough to justify the added tool.

改善不一定就是好的投資

發現 01 回答的是一個問題：哪一個加一台工具的方案，最能降低整條線的平均 cycle time。

但這還不是完整決策。每個 +1 tool 方案都有成本，cycle time 變短也不一定足以合理化新增機台。

Dollar values are illustrative, not real factory quotes. They are used to compare scenarios under the same assumptions.

金額是示意值，不是真實工廠報價或財務預測；用途是在相同假設下比較不同方案。

Calculation: Net cost change = scenario total cost - baseline total cost. Total cost includes processing cost (tool busy-hours × illustrative processing rate), waiting / congestion cost (lot queue-wait hours × illustrative holding rate), and added tool cost (number of added tools × illustrative tool cost). Negative saves versus baseline; positive costs more.

計算方式：淨成本變化 = 方案總成本 - 基準總成本。總成本包含處理成本（工具忙碌時數 × 示意處理費率）、等待 / 壅塞成本（lot 排隊等待時數 × 示意持有費率），以及新增機台成本（新增機台數 × 示意機台成本）。負值代表相對基準省錢；正值代表成本增加。

Processing consumes tool time, energy, labor, and maintenance resources. Waiting creates WIP burden, longer lead time, and congestion risk.

處理會消耗工具時間、能源、人力與維護資源；等待會造成 WIP 負擔、lead time 變長與壅塞風險。

The exact dollar values are less important than the decision result. Under these assumptions, LITHO is the only net-saving option, and the recommendation remains LITHO when the cost assumptions are varied by ±50%.

精確金額不是重點，決策結果才是重點。在這些假設下，LITHO 是唯一淨節省的方案；即使成本假設上下變動 ±50%，建議仍然是 LITHO。

When metrics conflict

If the goal is lead-time reduction, choose the option that meets the cycle-time target at an acceptable cost.

If the goal is financial return, choose the option with the strongest net saving or payback.

If both matter, first define the minimum operational improvement required, then choose the most cost-effective option that meets it.

當指標衝突時

如果目標是縮短 lead time，選擇能在可接受成本內達成 cycle-time 目標的方案。

如果目標是財務回報，選擇淨節省或回收效果最強的方案。

如果兩者都重要，先定義最低需要的營運改善幅度，再選擇符合條件且最具成本效益的方案。

In this simplified scenario, LITHO passes both filters: it reduces average cycle time the most and is the only option with net savings under the illustrative cost model. Among these four +1 tool options, LITHO is the recommended option.

在這個簡化情境中，LITHO 同時通過兩個篩選：它讓平均 cycle time 降幅最大，也是示意成本模型下唯一有淨節省的方案。在這四個 +1 tool 選項中，LITHO 是建議方案。

This is not an automatic buying rule. It is a decision-support workflow: validate the baseline model, test feasible capacity scenarios, translate operational improvement into illustrative cost impact, and check whether the recommendation is robust to cost assumptions.

這不是自動採購規則，而是一個 decision-support workflow：先驗證基準模型，再測試可行的產能方案，將營運改善轉換成示意成本影響，並檢查建議是否能承受成本假設的變動。

03

Slow degradation is expensive — but catchable

A machine quietly slowing down barely changes output, so nobody notices — while it silently piles up a large cost. An early-warning monitor flags it in time to avoid almost all of it.

緩慢劣化很貴——但抓得到

機台悄悄變慢,產出幾乎不變,所以沒人察覺——但成本卻在背後默默累積。一個早期預警監控能及時 抓到,幾乎把損失全部避掉。

What this is really about

Turning messy operational data into clear, defensible decisions. Every number here is traceable to a raw log row or a stated assumption, and every method is explainable from first principles — no black boxes. Decisions an operations team can act on, and argue with.

這個專案真正想傳達的
