01

Local metrics show candidates, not the final answer

Local metrics identify which stations deserve attention, but they do not directly answer which capacity addition improves the whole line most. FURNACE is slow per batch and processes the most lots per run, while LITHO has the highest utilization. The decision needs a system-level what-if comparison.

局部指標能指出候選站點，但不是最後答案

局部指標可以告訴我們哪些站點值得注意，但不能直接回答「加哪一站的產能，對整條線改善最大」。 FURNACE 單批加工時間最長、每次運轉可處理最多 lots；LITHO 的稼動率最高。因此還需要用整體系統的 what-if 比較來判斷。

Each scenario adds one tool to one station. The question is not only how many lots the added tool can process, but whether adding it actually reduces the whole line's average cycle time.

FURNACE looks important because one added tool can process 4 lots at a time. But adding one FURNACE tool only reduces average cycle time by about 0.70 hours. Adding one LITHO tool processes only 1 additional lot at a time, but reduces average cycle time by about 2.46 hours. In this scenario, the better capacity decision is the station that reduces whole-line cycle time the most, not the station that adds the most lot-processing slots.

02

A visible improvement can still lose money

Buying a tool at the wrong station can make a metric look better and still destroy value. Only the bottleneck investment pays for itself; every other option here costs more than doing nothing at all.

看得到的改善,也可能是賠錢的

在錯的站買機台,數字會變好看,錢卻是虧的。只有投資在瓶頸上才會回本;其他每一個選項,都比 「什麼都不做」還要貴。

03

Slow degradation is expensive — but catchable

A machine quietly slowing down barely changes output, so nobody notices — while it silently piles up a large cost. An early-warning monitor flags it in time to avoid almost all of it.

緩慢劣化很貴——但抓得到

機台悄悄變慢,產出幾乎不變,所以沒人察覺——但成本卻在背後默默累積。一個早期預警監控能及時 抓到,幾乎把損失全部避掉。

What this is really about

Turning messy operational data into clear, defensible decisions. Every number here is traceable to a raw log row or a stated assumption, and every method is explainable from first principles — no black boxes. Decisions an operations team can act on, and argue with.

這個專案真正想傳達的

把雜亂的營運數據,變成清楚、站得住腳的決策。這裡每個數字都能追溯到一筆原始紀錄或一個明講的 假設,每個方法都能從第一原理解釋清楚——沒有黑盒子。是營運團隊能拿去執行、也能拿來反駁的決策。
