KPI Baseline: The starting point for the three findings

These charts are not a standalone dashboard. They are the shared baseline behind the three findings. Output, WIP, utilization, cycle time, and X-factor provide the reference point for bottleneck diagnosis, investment trade-off, and degradation monitoring.

KPI Baseline：三個 findings 的共同起點

這些圖不是單獨展示的 dashboard，而是三個 findings 共用的基準證據。Output、WIP、utilization、cycle time 和 X-factor 提供判斷瓶頸、比較投資取捨，以及監控劣化是否先造成等待成本的參考點。

How this baseline supports the findings這組 baseline 如何支援三個 findings

The baseline charts identify signals and context. The findings then test those signals with what-if simulation, cost modeling, and monitoring backtests.

Baseline 圖表提供訊號與背景，後面的 findings 再用 what-if simulation、成本模型與 monitoring backtest 進一步測試。

Finding 01: Bottleneck diagnosis starts from local signals

Utilization shows which stations are close to full load. WIP and cycle time show whether lots are waiting and accumulating. These signals identify bottleneck candidates, then Finding 01 uses +1 tool what-if tests to verify whether LITHO is the true constraint.

Finding 01：瓶頸診斷從局部訊號開始

Utilization 顯示哪些站點接近滿載。WIP 和 cycle time 顯示 lot 是否正在等待與累積。這些訊號指出瓶頸候選站點，Finding 01 再用 +1 tool what-if 測試確認 LITHO 是否是真正限制。

Finding 02: Investment decisions need more than cycle-time reduction

Cycle time measures the operational impact of an improvement, but capacity decisions cannot rely only on time reduction. Finding 02 connects +1 tool scenarios to cost impact and checks whether cycle-time improvement and investment cost create a trade-off.

Finding 02：投資決策不能只看 cycle time 降幅

Cycle time 衡量改善方案的營運影響，但產能決策不能只看時間下降。Finding 02 把 +1 tool 情境連到成本影響，檢查 cycle-time 改善與投資成本是否形成 trade-off。

Finding 03: Degradation can appear before output drops

Output shows whether production has visibly dropped. Cycle time, WIP, and X-factor show whether waiting and congestion are already building up. Finding 03 compares output-only monitoring with drift monitoring before output makes the issue obvious.

Finding 03：劣化可能先出現在 cycle time，而不是 output

Output 顯示產出是否明顯下降。Cycle time、WIP 和 X-factor 顯示等待與壅塞是否已經累積。Finding 03 用這個想法比較只看 output 的監控與 drift monitoring。
